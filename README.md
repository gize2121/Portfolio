# Gizachew Tilahun Feleke — IT Portfolio

## Deploy on Render
1. Create a GitHub repository named `gizachew-portfolio`.
2. Upload `index.html` to the repository root.
3. In Render, select **New + → Static Site** and connect the repository.
4. Use branch `main`.
5. Leave **Build Command** blank.
6. Set **Publish Directory** to `.`.
7. Click **Create Static Site**.

## Before publishing
- In `index.html`, replace `YOUR_EMAIL@example.com` with your professional email.
- Check job dates and descriptions for accuracy.
- If adding a CV PDF, upload it to the same repository and add a link to it in the page.
